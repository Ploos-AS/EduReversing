# Encoding and obfuscation analysis

## Observation

Describe the bytes/code pattern without assigning intent.

## Transformation hypothesis

Document input, output, width, constants/key material and operation order.

## Reproduction

Show how the original representation is decoded or normalized.

## Classification

Distinguish encoding, compression, encryption, compiler transformation and deliberate obfuscation only when evidence supports the distinction.

## Intent

Do not infer malicious intent from obfuscation alone. Record intent as unknown unless supported by independent evidence.

## Analysis-sensitive signals

For each suspicious-looking signal record reachable-code evidence, runtime evidence, alternative explanations and what would falsify the hypothesis.
