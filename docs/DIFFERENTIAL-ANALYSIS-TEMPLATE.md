# Differential analysis template

## Pair identity

Record hashes, executable format, architecture and build provenance for both versions.

## Function correspondence

| v1 function/evidence | v2 function/evidence | Why these correspond | Confidence |
|---|---|---|---|

Do not use virtual address equality as the sole matching rule.

## Difference inventory

| Location/evidence | v1 | v2 | Semantic / presentation / layout / unresolved | Cross-check |
|---|---|---|---|---|

## Behavioral hypothesis

State the smallest proposed semantic change and give an input that should distinguish the versions.

## Runtime result

Record the predicted and observed outputs.

## Patch interpretation

Explain the conceptual patch represented by the changed machine code. The goal is understanding the update, not modifying protections.

## Remaining uncertainty

List differences that have not been explained.
