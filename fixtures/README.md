# Course fixtures

Fixtures in this directory are purpose-built, benign programs for reverse-engineering education.

They are **not malware** and must not be presented as captured malware. Source is retained for auditability and reproducibility. Student exercises should direct learners to analyze generated binaries before reading the corresponding source.

Do not add real malware, weaponized samples, stolen binaries, credential material, or unknown binaries of uncertain provenance.

The generated `build/` artifacts are intentionally not committed. Build them locally from reviewed source.
