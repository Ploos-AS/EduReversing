# Incident 01 — synthetic evidence bundle

Everything in this directory is inert, course-owned text evidence. It does not create files, processes, persistence, or network traffic.

The IP address uses the RFC 5737 TEST-NET-1 documentation range and the hostname uses the reserved `.invalid` top-level domain.

Treat the files as observations collected from a hypothetical endpoint. Their presence in the repository is not evidence that the recorded activity occurred on the analysis host.
